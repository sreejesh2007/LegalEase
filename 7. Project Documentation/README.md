# 7. Project Documentation – LegalEase

## 1. Project Overview

LegalEase is an AI-powered legal document generation application that helps users create customizable legal document drafts using Generative AI.

The application uses FastAPI as the backend framework and Gemini AI for document generation. Users can enter important details, generate a document draft, edit the generated content, and export the document in different formats.

---

## 2. Main Features

- AI-powered legal document generation
- Multiple document types
- Custom user inputs
- Editable document preview
- Automatic term table
- Custom branding
- Font selection
- TXT export
- DOCX export
- PDF export
- FastAPI backend
- Gemini AI integration
- Input validation
- Error handling
- Health-check endpoint
- Secure API key handling

---

## 3. Supported Documents

LegalEase supports:

1. Non-Disclosure Agreement (NDA)
2. Employment Agreement
3. Lease Agreement
4. Service Agreement
